Votes and cash flows: Halden Robotics plc

A founder, two share classes and a plan to raise capital (slides 24 to 27). Enter your answers and check each step; once you have checked a step, you can also see its solution. Give percentages to one decimal place.

The facts (fictional)

  • Class A: 900m shares, one vote each, listed. Class B: 120m shares, ten votes each, unlisted. Both classes have the same rights to dividends.
  • The founder and CEO holds 110m Class B shares and no Class A shares. Class B shares become Class A shares when sold.
  • Halden needs to raise capital for a factory and is choosing between Plan A: issue 300m new Class A shares, and Plan C: issue 300m new non-voting Class C shares at the same price.
